# Daily Update — 2026-07-02

**Theme:** Detail tiers — one world, three zoom rungs (a Google-Earth → Google-Street rule for the map).

## What shipped today

The map now renders **different levels of detail depending on the zoom rung**, all deterministic from the same seeds:

- **Rung 0 — Overview (chart):** settlements collapse to icons — a border ring + an owner-colored seat marker + a name label. Roads only, no scatter. Villages stay a bare dot (no name).
- **Rung 1 — Strategic map (miniature):** unchanged — today's familiar pictogram world.
- **Rung 2 — Action (street level):** the same seed rebuilt at human proportion. Buildings tower (height ×3.0, footprint ×2.2, ~34% as many so districts stay full), walls/keeps/gates/streets on the **same ring** so roads still meet the walls exactly. Every map tree becomes a 3–5 tree stand, real fir/broadleaf tree models replace pictograms, boulders replace pebbles, and roadbeds paint wider (paint-only — routing/ETA untouched).

## How it works

- **Terrain re-tessellation by zoom:** rung 0 charts the land in 2× hexes (¼ the tiles), rung 1 keeps the canonical lattice, rung 2 splits the ground into half-size hexes (4× tiles) whose extra vertices sample the *true* kernel field for genuine close-up relief. Only the **render** lattice scales — the logical lattice (territory CA, server payloads, gameplay queries) is untouched.
- **Budgeted & distance-aware, so nothing hitches:** one street rebuild per frame (nearest hold first), a per-frame terrain re-tessellation queue, and fine tessellation only on the chunk ring around the hero. Action rung also pulls fog/clip-plane right in — a ground-level eye ends at the treeline, not the horizon.
- **Settlement grounds clear the scatter:** fields, gate aprons and mustering grounds ring every hold, so a town that reads clear on the map *is* clear when you drop into action — no phantom thickets at the gate.
- **Camera tuning:** field mode aims at the rig's true eye line (~2.9·scale); action camera pulled back a touch (dist 11, height 5.5·FS) to give street-scale buildings headroom.

## Server / persistence

- New **`chunk_detail`** table (migration `011_chunk_detail.sql`): street-level rows generated once with the shared kernel, gzip-JSON persisted on first visit (Google-Street rule — rows exist only where someone has walked), served at `GET /api/v1/chunks/detail`.
- Kernel now owns placement: `Terra.chunkScatter` / `Terra.chunkGroves` produce **byte-identical** rows client- and server-side, so the table is the *saved* canonical copy, not a correctness dependency. Local fallback stays in perfect parity.
- New client transport: `net.loadDetail(level, u, keys)` + client-side `srvDetail` cache.
